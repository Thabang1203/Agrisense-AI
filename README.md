## Agrisense-AI
AgriSense.AI is a water-first, AI-powered web application built to address South Africa's most pressing agricultural challenge: water scarcity. It serves both urban smallholders (rooftop, township, and backyard farmers in Cape Town, Johannesburg, Durban) and rural / commercial farmers (Free State maize, Eastern Cape livestock, Western Cape vineyards, Limpopo citrus).
